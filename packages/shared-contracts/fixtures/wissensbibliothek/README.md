# Testbibliothek (erfunden)

Kleine, frei erfundene Wissensbibliothek für die Unit-Tests der App (`KnowledgeLibraryTests`). Aufbau wie eine echte
Bibliothek (katalog.json, Bibliothek/<Fach>/…), aber kein echter Inhalt: alle Texte, Titel und Zahlen sind ausgedacht.
Zwei Fächer, drei Einheiten. `_pruefung.py` ist nur ein Platzhalter und wird von der App nie kopiert oder ausgeführt.
