# Audit 08.11.2026 – Pakete 30 bis 32 (KI-Tutor/Karteikarten, Stapel/Plan/Tests, Marker/Wochentests/Demo/Einstellungen)

Grundlage: externer, rein statischer Audit (`audit-pakete-25-32.md`, Abschnitte Paket 30–32, `app/server.py` Blob
`1862487f…` = Stand `develop` 0074c963). Jeder Punkt wurde gegen den Code geprüft und mit einem Test belegt
(`tests/test_audit_paket_30_32.py`, 85 Tests). Zutreffende Befunde: zuerst roter Test (Commit „rote Tests“, 67 rot
auf dem alten Stand), dann der kleinste Fix. Keine echten KI-Aufrufe (Attrappen `FakeAI`, `FakeCardsAI`, asynchrone
Attrappe wie in `tests/test_ai_lastfest.py`), kein Server, kein SSH.

Wichtig für die Bewertung: Im Dienst hat jedes Konto eine **eigene Datenbank** (`config.set_user_context` →
`data/users/<id>/…`). Zahlen-IDs aus einem anderen Konto treffen dort nie dessen Zeile; mit zwei Konten über die
ASGI-App geprüft für Karte, Stapel, Planeintrag und Test (`test_p31_foreign_ids_never_reach_another_account`).
Geteilt sind nur `accounts.db` (Credits, Kontingente, KI-Zwischenspeicher, Sperren) und die Pools (Wochenstapel,
Bibliothek).

Spalte „Betrifft“: **D** = Dienst (app.studinow.app), **PC** = Windows-/Einzelplatz-Version, **D+PC** = beide.
