# Mathematik für die Ingenieurwissenschaften I – Probeklausur 2

## Teil 1: Aufgaben

### Aufgabe 1 (2 + 2 Punkte)
Gegeben sind x = (1, 0, 1) und y = (1, 2, 2).
(a) Berechnen Sie den Winkel ∠(x, y).
(b) Berechnen Sie die Fläche des von x und y aufgespannten Parallelogramms.

### Aufgabe 2 (3 Punkte)
Bestimmen Sie den Abstand des Punktes X₀ = (2, 3, 0) von der Geraden L: (0, 1, 1) + s·(1, 0, 1).

### Aufgabe 3 (3 Punkte)
Für welche t ∈ ℝ sind x = (1, 2, t) und y = (2, 4, t² − 2) linear abhängig?

## Teil 2: Lösungen

### Aufgabe 1
**Merke:** cos ∠ = x·y / (‖x‖‖y‖), Fläche = ‖x × y‖.
(a)
x·y = 1 + 0 + 2 = 3, ‖x‖ = √2, ‖y‖ = 3
cos ∠(x, y) = 3 / (3√2) = √2/2
▶ **∠(x, y) = π/4**
(b)
x × y = (0·2 − 1·2, 1·1 − 1·2, 1·2 − 0·1) = (−2, −1, 2)
▶ **Fläche = 3**

### Aufgabe 2
Schritt 1: s = ((2, 2, −1)·(1, 0, 1)) / 2 = 1/2
Schritt 2: F = (1/2, 1, 3/2), X₀ − F = (3/2, 2, −3/2)
▶ **d = √34/2**

### Aufgabe 3
y = 2x verlangt t² − 2 = 2t, also t² − 2t − 2 = 0.
▶ **t = 1 ± √3**
**Wichtig für die Klausur:** Beide Lösungen der quadratischen Gleichung angeben.
